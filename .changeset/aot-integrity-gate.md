Make the production compilation contract a build-time guarantee. Analog builds the `client` and `ssr` environments concurrently with one shared Angular plugin, which discards its compilation output when the first environment ends; an environment still transforming then received no compiled output for its files, and Analog skipped them without failing, so a page or component reached the production server as an uncompiled `@Component` and Angular fell back to the JIT compiler on the first request (`JIT compiler unavailable`, HTTP 200, empty or partial document). The Vite plugin now holds each environment at `buildEnd` until every environment of the build has finished transforming, using only public Rollup hooks, and a post-transform gate fails a production build, naming the module, environment and class, when a source-owned Angular class still applies its decorator or a bundled package still contains unlinked partial declarations (`ɵɵngDeclare*`). Valid builds are unchanged; a build that used to succeed and ship a server that could not render a component now fails with an actionable error. No option or API was added.
