## Implemented and locally integrated

`tools/server-components/lib/failures.ts` adds a browser-controlled negative case to the existing
failure harness. Before Chromium receives the response, the harness renames one SSR boundary in
host B from `<failure-island>` to `<missing-island>` while retaining its SSR subtree and Angular
hydration attributes. The browser preflight finds no matching registered reference and refuses
the entire host with category `reference`. This does not weaken or bypass Vite analysis: the
fixture is a controlled mutation of SSR boundary metadata, testing the established runtime
preflight layer.

The test asserts one `StrataBoundaryError` through Angular `ErrorHandler`, exactly one
`preflight-refused` host event with `failureCategory: "reference"`, zero committed boundaries,
`buildMismatch: false`, no island construction, no hydrated markers, unchanged DOM node identity
and positions, inert server output, working independent sibling hosts, no page error or unhandled
rejection, no retry, and one document request with the same JavaScript realm. The same scenario
passes on Nitro Node and local Wrangler Pages/workerd. Existing protocol and resource refusal
cases run in the same suite: protocol 999, the 128-boundary ceiling and the 1 MiB aggregate limit
all retain all-or-nothing behavior. Protocol v1 is exercised by the failure fixture; both v1 and
v2 are covered by the packed positive consumer.

**Evidence level:** IMPLEMENTED, UNIT TESTED (existing registry tests), LOCALLY INTEGRATED
(Node + Chromium and workerd + Chromium). The browser negative is an unknown boundary selector;
it does not exercise a malformed generated descriptor or descriptor accessor throwing inside
`buildClientReferenceRegistry`. Those descriptor cases remain unit-only.

## Follow-up: hostile descriptor accessor in a real browser

On 2026-10-30, from current `origin/main` SHA `919994f1dba052be6d05085ceb04a69ba4f6ec2f`, the same failure harness gained a controlled browser-only registry mutation. Before scripts execute, the harness wraps `Object.getOwnPropertyDescriptor` for the generated `failure-island` descriptor on host B and presents its `expectedSelector` property as a throwing accessor descriptor. The callback restores the native method immediately after the targeted inspection, counts the two matching host registrations, and records whether the accessor body was invoked. No component source, Vite analyzer, generated production code or runtime implementation is modified.

Nitro Node and local Wrangler Pages/workerd Chromium runs both pass. Each records exactly one `StrataBoundaryError` with category `reference`, one `preflight-refused` event with zero committed boundaries and `buildMismatch: false`, no component construction or hydration for B, preserved SSR node identity, working A/C siblings, no page error or unhandled rejection, no retry, and a fresh healthy document lifecycle on re-entry. The accessor body throws a canary if invoked; the test verifies zero invocations and excludes the canary from diagnostics.

**Evidence level:** LOCALLY INTEGRATED (Node + Chromium, workerd + Chromium). This qualifies the runtime's safe rejection of an accessor-shaped descriptor in-browser; it does not prove Vite or Angular can emit malformed descriptors, and it does not replace compiler/analyzer negatives or the installed-package negative matrix. Hosted CI for the follow-up remains pending until the PR run completes.
