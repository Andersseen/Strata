# Support

Strata is experimental and support is provided in the open through GitHub.

- For a reproducible defect, use the bug report template.
- For a focused product idea, use the feature proposal template.
- For security-sensitive reports, follow [SECURITY.md](./SECURITY.md).
- For architecture, release gates, and current constraints, begin with
  [docs/README.md](./docs/README.md) and [docs/STATE.md](./docs/STATE.md).

Before opening an issue, search existing discussions and include the exact
Strata commit or package version plus Node.js, package-manager, and runtime
versions. That makes experimental compatibility work much easier to verify.
